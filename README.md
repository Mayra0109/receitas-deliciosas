# 🍲 Receitas Caseiras

Um site simples, organizado e visualmente bonito para apresentar receitas caseiras.

## Funcionalidades
- Busca por receitas
- Filtros por categoria
- Organização por doces, salgados, bebidas e sobremesas
- Modal com ingredientes e modo de preparo
- Layout responsivo

## Como abrir
Basta abrir o arquivo `index.html` no navegador.

## Estrutura
- `index.html` — página principal
- `styles.css` — estilos do site
- `script.js` — receitas e interatividade
